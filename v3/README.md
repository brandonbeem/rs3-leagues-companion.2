# RS3 Leagues Companion V3

This folder is the modular, free-only successor to the stable V20 single-file application.

## Stack

- React
- TypeScript
- Vite
- GitHub
- Netlify
- Browser localStorage for early local-first persistence

No paid service is required for the current foundation.

## Commands

```bash
npm install
npm run dev
npm run build
```

## Migration rule

V20 remains the stable source of truth until each V3 system has been rebuilt and tested through a Netlify deploy preview.
