RuneScape 3 Catalyst League Companion

## Fort Forinthry preview testing

The `agent/fort-forinthry-dependency-engine` branch adds an isolated Fort planner to the v21 Netlify preview.

1. Open the branch deploy preview.
2. Click **🏰 Fort Planner** in the bottom-right corner.
3. Use **Progress** to set Construction, Necromancy, quests, buildings, and boss completion.
4. Use **Materials** to enter available Fort frames and stone wall segments.
5. Return to **Next Steps** to review ready actions and the closest blocked goals.

Test values are saved only in local browser storage. The live `main` deployment is unchanged until the pull request is merged.
